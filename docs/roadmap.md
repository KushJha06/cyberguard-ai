# Roadmap

## 0.2 — Analyst experience

Professional console, nine explainable rules, file-integrity workflow, local playbooks, and portable reports.

## 0.3 — Source ecosystem

Wazuh, Zeek, Sysmon, Docker, OpenTelemetry, syslog, and configurable YAML rules.

## 0.4 — Operations

Incident status transitions, deduplication windows, retention controls, background jobs, signed report bundles, and role-based authentication.

## 0.5 — Assisted analysis

Optional local-model root-cause synthesis with strict schema validation, provenance, prompt-injection defenses, and deterministic fallback. No autonomous remediation.
