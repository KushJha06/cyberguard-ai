# Security Policy

Report vulnerabilities privately to the project maintainers; do not open a public issue containing exploit details or real telemetry.

CyberGuard is an advisory triage tool, not an enforcement control. Treat uploaded telemetry as sensitive. Run it locally or behind authenticated, encrypted access. The MVP has no built-in authentication and is not intended for direct Internet exposure.

Never upload production secrets. Automatic redaction is best-effort and cannot guarantee removal of every credential or personal identifier.
